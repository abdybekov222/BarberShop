# Защита финального проекта — чек-лист требований

Проект: **BARS Barber Club** — сайт барбершопа с онлайн-записью, магазином косметики и ИИ-примеркой.
Стек: Next.js 14 (App Router, TypeScript, Tailwind, Redux Toolkit) + NestJS + PostgreSQL (Prisma).

## Базовые функции

| Требование | Где в проекте |
|---|---|
| Корзина | `/cart` — Redux Toolkit (`frontend/src/store/cartSlice.ts`), сохранение в localStorage |
| Бронь | `/booking` — пошаговая запись к мастеру, защита от двойной брони в БД |
| Регистрация / логин | `/auth` — email + пароль (собственный API, валидация телефона +996) и Google |
| Заказ / купить | `/checkout` → `POST /api/orders` (`backend/src/shop/orders.service.ts`) |
| Админ-панель | `/admin` — статистика, записи, заказы, товары, мастера, отзывы, ИИ, настройки |
| Подробное описание товара | `/shop/[slug]` — описание, применение, объём, отзывы, похожие товары |
| Поиск по имени | `/shop?q=…` и поиск в шапке (лупа) — по названию и бренду |
| Фильтрация товаров | категория, цена от/до, «только в наличии», сортировка (5 вариантов) |
| Добавить / удалить товар | Админка → «Товары»: создание, редактирование, удаление, загрузка фото |
| Переводчик kg-ru-en | Переключатель KG / RU / EN в шапке (`frontend/src/i18n/`) |
| Адаптивный дизайн | Mobile-first, 360 px → десктоп, без горизонтального скролла |
| Оформить заказ | Самовывоз или курьер, оплата при получении или картой (демо) |
| Бургер-меню | Мобильное меню на весь экран (`components/Header.tsx`) |
| Тема день–ночь | Кнопка солнце/луна в шапке, CSS-переменные, без мигания при загрузке |
| Избранное | Сердечко на товаре → `/favorites` (Redux + localStorage) |
| Отзывы / рейтинг | Отзывы о товарах и мастерах, рейтинг пересчитывается на сервере |

Данные всегда приходят **через API** (NestJS, `backend/src`), компонентов `.tsx` во фронтенде — 68.

## Дополнительные функции

| Требование | Реализация |
|---|---|
| JWT Auth + Private Routes | Собственный JWT (`backend/src/auth/jwt.ts`), глобальный `JwtAuthGuard`; `/checkout`, `/account/*`, `/admin` без входа перенаправляют на `/auth` |
| Пагинация | Каталог магазина (`components/shop/Pagination.tsx`), заказы в админке |
| Google OAuth | «Войти через Google» на `/auth` |
| Admin CRUD | Товары, услуги и цены, мастера (отпуска), отзывы (модерация), образы ИИ |
| Loading skeleton UI | `app/shop/loading.tsx`, скелетоны карточек, графиков, заказов |
| Error boundary | `app/error.tsx` (500), `app/not-found.tsx` (404) |
| Chart / статистика (recharts) | Админка → «Статистика»: выручка, записи по дням, загрузка мастеров, топ товаров |
| Role-based access | Роли client / master / admin / owner, `RolesGuard` на всех `/api/admin/*` |
| Payment (demo) | Оплата картой в демо-режиме, тестовая карта `4242 4242 4242 4242` |
| Multilanguage (i18n) | ru / ky / en, язык хранится в cookie и работает и на сервере |
| Image upload | Фото товаров из админки: сжатие в WebP (sharp), хранилище API |

## Бонусы

| Бонус | Реализация |
|---|---|
| Telegram-бот | Уведомления о записях и заказах с кнопками «Подтвердить / Отменить / Собран / Выдан», команды `/today`, `/orders`, привязка аккаунта клиента для напоминаний (`backend/src/notifications/telegram-bot.service.ts`) |
| Заказ на почту | Письмо клиенту после оформления заказа (`mail.service.ts`, nodemailer) |
| API-интеграции | Google Gemini (ИИ-зеркало), Telegram Bot API, Google sign-in, OpenStreetMap, Neon Postgres |
| ИИ | «Виртуальное зеркало» — примерка стрижки по фото, лимит 3 попытки, бюджет |

## План выступления (5 минут)

1. **Проблема** (30 с): барбершопы в Бишкеке записывают по телефону, клиент не знает, пойдёт ли ему стрижка.
2. **Решение** (30 с): онлайн-запись, ИИ-примерка и магазин в одном месте.
3. **Демо** (3 мин): главная → смена языка и темы → запись к мастеру → магазин (поиск, фильтр, карточка, корзина, оформление с демо-оплатой) → уведомление в Telegram → админка (графики, товары, заказы).
4. **Технологии** (40 с): Next.js + Redux Toolkit, NestJS + Prisma + PostgreSQL, JWT, Telegram Bot API.
5. **Итог** (20 с): что сделано и что дальше (SMS-вход, реальная оплата).
